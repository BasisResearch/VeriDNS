# W4 hypothesis audit — slice: Refinement / ResolveWithIOSound / FreeIO / WorldNetwork / NetworkSim

Date: 2026-07-15. Read-only audit per `docs/model-strengthening-plan.md` §W4.
Slice: `VeriDNS/Proof/Refinement.lean` (462 thms), `VeriDNS/Proof/ResolveWithIOSound.lean` (~85),
`VeriDNS/Proof/FreeIO.lean` (~90), `VeriDNS/Proof/WorldNetwork.lean` (~30),
`VeriDNS/Proof/NetworkSim.lean` (~120). Plus the mandated special-attention items
(`resolveWithIO_complete`, `resolveWithIO_spine_adequate_warm`, `resolveThenReply_sound`,
the `WorldModels` pack) whose statements live outside the slice but whose packs are defined
or consumed inside it.

Method: textual/structural analysis of every capstone and every hypothesis-bearing theorem
family; `grep` for producers/consumers repo-wide; one `lean_minimal_hypotheses` run
(`run_ioResumeLoop_answer`, result triaged below). Mechanical lemma families (bridge/congruence/
invariant-preservation) audited by representative and classified at family level.

Classes: **U** = Unused, **UR** = Unrealistic / undischarged, **OS** = Over-scoped conclusion,
**LB** = Load-bearing and fair, **DS** = documented scope limit (fair, but recorded).
